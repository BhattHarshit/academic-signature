# Customization

## Global profile

Start with `_data/profile.yml`. It contains the information a site owner is expected to personalize: identity, affiliation, contact details, site URL, social handles, portrait, repositories, CV behavior, blog metadata, and optional comments.

Academic content remains independent in `_pages/`, `_projects/`, `_teachings/`, `_news/`, `_posts/`, and `_bibliography/`.

## Portrait

Replace `assets/img/profile.png`. If you use another filename, update `profile.image` in `_data/profile.yml`.

## Social links

The starter ships with example GitHub, LinkedIn, Google Scholar, and ORCID values so visitors can see the available icons. Replace them in `_data/profile.yml`:

```yaml
socials:
  email: you@example.edu
  github_username: your-github-username
  linkedin_username: your-linkedin-handle
  scholar_userid: YOUR_SCHOLAR_ID
  orcid_id: 0000-0000-0000-0000
  rss_icon: true
```

Set any unused service to `""` and it will be omitted automatically.

## CV

Replace `assets/pdf/demo-cv.pdf` and set:

```yaml
cv:
  pdf: /assets/pdf/my-cv.pdf
  website_view: false
```

- `website_view: false` embeds the PDF and shows **Download CV**.
- `website_view: true` shows the web CV and keeps **Download CV** plus **Open PDF**.

Edit `_data/cv.yml` only when you use the web CV.

## News

Add entries to `_news/`. The newest items appear automatically under Recent Updates on the homepage and in the full News archive.

## Navigation

New `_pages/*.md` files become navbar items unless `nav: false` is set. Use `nav_order` for an explicit order.

## Detail-page return links

Projects, teaching pages, news items, and blog posts receive automatic return links. For another nested page, add:

```yaml
section_label: Research
section_url: /research/
```

## Mathematics

Use MathJax delimiters. For display equations:

```latex
$$
A = U\Sigma V^T.
$$
```

## Search

`_plugins/signature_search.rb` builds `/assets/search-index.json`; `assets/js/signature-search.js` provides the client-side full-site search. Its runtime settings are intentionally kept out of `_data/profile.yml` because routine site owners do not need to edit them.

The Publications page keeps its separate bibliography search.

## Sitemap

`/sitemap/` is the human-readable navigation page. `/sitemap.xml` is generated by `jekyll-sitemap` for search engines.

## Footer

The public footer reads `© YEAR Your Name. Built with Academic Signature.` Template-source and footer-display settings are maintained internally rather than in `_data/profile.yml`.

## Favicons

All favicon and web-app icon files are kept together in:

```text
assets/img/favicons/
```

The active favicon and Apple touch icon paths are configured internally in `_config.yml`. Replace files in this folder only if you want to rebrand the Academic Signature icon set.
